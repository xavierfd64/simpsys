# BizManager

Multi-tenant Laravel SaaS for small food business management — POS, inventory,
kitchen orders, expenses, reports, subscriptions, and a Super Admin platform.

See [`CLAUDE.md`](./CLAUDE.md) for architecture decisions, stage progress, and
local setup. The full product specification lives in
[`spec/Small_Food_Business_SaaS_COMPLETE_PACKAGE/`](./spec/Small_Food_Business_SaaS_COMPLETE_PACKAGE).
